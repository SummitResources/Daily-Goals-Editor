# The Daily Goals Editor

Since I find it difficult to edit large amounts inside an Excel cell on a Mac, I had Claude make this.  The main screen allows you to specify an activity (such as "Complete Documentation for PROD-1331" ... and aill parse out the ticket number, and allow you to enter sub-items.  Should be self-explanatory beyoind that.  

## To Excel

When done, on the right-hand side at the bottom is a text box with a clipboard copy button that will copy the generated text so you can paste it directly into Excel.

## Known issues

May not compile on everyone's Mac.  Apple is picky about it's XCode version and such.
Is built for .NET 11.
Code is rudimentary Claude code w/o significant revision by a human, so... use at your own risk.
